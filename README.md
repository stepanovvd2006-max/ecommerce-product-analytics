# Продуктовый и бизнес-анализ интернет-магазина косметики (eCommerce)

Сквозной анализ пользовательского поведения, продуктовой воронки, сезонности и клиентских сегментов на основе логов событий интернет-магазина за декабрь 2019 года (**3 533 286 событий**, **358 212 уникальных пользователей**).

## Архитектура и стек технологий
* **PostgreSQL + SQLAlchemy:** локальное хранение 3,53 млн записей, индексация (`user_id`, `event_type`, `event_time`) и перенос тяжелых вычислений на сторону СУБД (*push-down computation*) для минимизации нагрузки на оперативную память.
* **SQL (PostgreSQL):** условная агрегация (`FILTER`), табличные выражения (`CTE`), оконные функции (`OVER ()`), работа с временными рядами и очистка аномалий.
* **Python (Pandas, Matplotlib):** обработка агрегированных витрин и визуализация бизнес-метрик.

## Основные этапы исследования
1. **Разведка и очистка данных (EDA):** выявлено ~98,3% пропусков в текстовых категориях (`category_code`) и 42,7% в брендах (`brand`), а также 18 транзакций с отрицательной ценой (возвраты/корректировки). Сформулированы правила фильтрации витрин.
2. **Воронка конверсии:** из 358 212 пользователей, просматривавших товары (`view`), в корзину (`cart`) добавили позиции 83 458 человек (**23,3%**), а покупку (`purchase`) совершили 25 613 покупателей (общая конверсия **7,15%**).
3. **Анализ брендов:** товары без указанного бренда (`unknown`) принесли **440 747** выручки (40,9% оборота — критическая точка роста для заполнения каталога). Среди известных брендов по выручке и конверсии лидируют бюджетные расходники (**runail** — выручка 58 177, конверсия 16,84%; **grattol** — 43 793; **irisk** — 35 291, конверсия 15,91%).
4. **Поведенческая сегментация клиентов:** 12,92% покупателей (3 310 оптовиков/мастеров, покупающих 16+ позиций) приносят **33,21% всей выручки** со средним LTV **108.17** (в 4 раза выше розницы). Активные клиенты (6+ товаров — 48,11% базы) формируют **69,49%** оборота.
5. **Сезонность и временные паттерны:** выявлена четкая недельная цикличность (спады по субботам и пики в понедельник–вторник), предновогодний максимум 9–16 декабря и резкий спад после 25 декабря.
