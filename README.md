# Продуктовый и бизнес-анализ интернет-магазина косметики (eCommerce)

Сквозной анализ событий интернет-магазина косметики за декабрь 2019 года (**3,53 млн событий**, **358,2 тыс. пользователей**).
**[Открыть интерактивный дашборд в Yandex DataLens](https://datalens.yandex/2h0zxl73c6qil?_share_link=public)**

## Стек и архитектура
* **PostgreSQL + SQLAlchemy:** хранение 3,53 млн записей, индексация и push-down вычисления.
* **SQL:** агрегации, CTE, оконные функции, расчет конверсий и очистка аномалий.
* **Python (Pandas, Matplotlib):** работа с витринами и визуализация.

## Главные выводы исследования
1. **Воронка и метрики:** 
   * По пользователям: просмотры — 358 212, корзины — 83 458 (23,30%), покупки — 25 613 (общая конверсия 7,15%, по сессиям — 3,64%).
   * Финансы: средний чек (AOV) — 37.31, средняя цена товара — 5.06, повторные покупатели — 9,68%.
2. **Качество данных:** обнаружены пропуски в категориях (98,3%) и брендах (42,7%), а также 18 транзакций `purchase` с отрицательной ценой (отфильтрованы).
3. **Бренды:** безымянные товары (`unknown`) приносят 40,88% выручки. Лидеры по конверсии — бюджетные расходники (runail, grattol, irisk), а дорогое оборудование (strong, marathon) показывает конверсию ниже 2%.
4. **Сегментация:** 12,92% клиентов (B2B/мастера с 16+ позициями) дают 33,21% выручки при LTV в 4 раза выше розничного. На активных клиентов (6+ товаров) приходится 69,49% оборота.
5. **Брошенные корзины и сезонность:** более 82,5% сессий с корзиной не завершаются покупкой (удалений 71,7%). Фиксируется недельная цикличность и предновогодний пик 9–16 декабря.
